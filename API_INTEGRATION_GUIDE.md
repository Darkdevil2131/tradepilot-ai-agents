# API Integration Guide

Base URL locally: `http://127.0.0.1:8000`. The hosted base URL is unknown until an eligible deployment is provisioned.

All endpoints except health require `Authorization: Bearer <API_KEY>`. Keep the API key in a backend secret store; do not ship it to a browser/mobile client.

## Analyze shipment

```bash
curl -X POST http://127.0.0.1:8000/api/v1/shipments/analyze \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_LOCAL_API_KEY' \
  --data @examples/analyze_shipment.json
```

The response includes an `agents` object with per-agent status, results and provenance. `route_optimization` values are estimates; `carrier_research` records are synthetic; quotes are user-provided; the analysis is not a booking. `document_intelligence` is marked skipped when no documents are supplied.

## Retrieve saved analysis

```bash
curl http://127.0.0.1:8000/api/v1/shipments/DEMO-001 \
  -H 'Authorization: Bearer YOUR_LOCAL_API_KEY'
```

Retrieval succeeds only while the saved record remains in the configured SQLite database. A deployment with ephemeral disk can lose records.

## Validate documents

```bash
curl -X POST http://127.0.0.1:8000/api/v1/documents/validate \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_LOCAL_API_KEY' \
  -d '{"shipment":{"origin":"Mumbai","destination":"Singapore","cargo_description":"parts","weight_kg":100,"documents":[]}}'
```

## Errors

- `401`: bearer key missing or invalid.
- `422`: invalid request shape or field values.
- `404`: no saved shipment with that ID in this database.
- `503`: server API key is not configured.
- `500`: safe generic error; details remain in server logs.

## Sample offline response shape

The specific route estimates are computed for each request. This abbreviated example shows the response structure only:

```json
{
  "shipment_id": "DEMO-001",
  "status": "completed",
  "persistence": "sqlite_ephemeral_or_local",
  "data_provenance": ["ESTIMATED", "SYNTHETIC", "USER_PROVIDED"],
  "agents": {
    "route_optimization": {"agent": "route_optimization", "status": "completed", "provenance": ["ESTIMATED"], "data": {"routes": "computed estimates"}, "warnings": []},
    "carrier_research": {"agent": "carrier_research", "status": "completed", "provenance": ["SYNTHETIC"], "data": {"carriers": "synthetic fixtures"}, "warnings": []},
    "risk_compliance": {"agent": "risk_compliance", "status": "completed", "provenance": ["USER_PROVIDED"], "data": {"live_screening": false}, "warnings": []},
    "document_intelligence": {"agent": "document_intelligence", "status": "skipped", "provenance": [], "data": {}, "warnings": ["No documents supplied."]},
    "market_procurement": {"agent": "market_procurement", "status": "completed", "provenance": ["ESTIMATED"], "data": {"recommendation": "computed only from eligible submitted quotes"}, "warnings": []},
    "logistics_orchestrator": {"agent": "logistics_orchestrator", "status": "completed", "provenance": ["USER_PROVIDED"], "data": {"workflow": "LangGraph StateGraph", "bounded_attempts": 2}, "warnings": []}
  },
  "summary": "Analysis completed using deterministic offline tools. No live carrier, route, customs, or market feeds were queried."
}
```

OpenAPI is generated by FastAPI at `/openapi.json`; interactive docs are at `/docs`.
